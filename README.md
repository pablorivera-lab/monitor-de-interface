# **Monitor de Interfaz**

Esta herramienta permite realizar un monitoreo rápido de la interfaz de red, facilitando la visualización del estado y la velocidad de la conexión mediante un script ligero y directo.

## **Características**

> * Script por lotes (.bat) para una ejecución sencilla en entornos Windows.  
> * Visualización intuitiva del rendimiento de la red.  
> * Ligero y sin dependencias externas complejas.
